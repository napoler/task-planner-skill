# release-review · 部署/发布质量审查

review-library 兜底池的发布领域审核技能,消费 Rule 42.2 四级检测链第④层。当任务为上线前审查、环境迁移、发布预案、回滚预案制定或部署后验证等发布类工作时,用本技能按发布质量维度做专项审查。
输出二值 `APPROVED` / `CHANGES_REQUESTED`,每条结论必须附机器可复现证据。

## 触发条件
- Rule 42.2 四级检测命中第④层「task-planner 内置 review-library 兜底池」,且任务类型匹配为「部署/发布/迁移/回滚预案/上线前审查」→ 命中本技能。
- 任务产出含发布计划/部署脚本/迁移脚本/回滚预案文档任一项,且变更将作用于生产或共享环境。
- 交付前做「发布质量门」,或用户/审查者显式要求「上线前/发布质量」审查。
- 命中专用审查规则的任务优先专用规则;本技能只处理兜底池内发布面,不替代、不叠加。
- 纯本地/纯开发环境、无对外影响的变更不触发;仅代码改动未涉部署面时归 code 面审查。
- 涉及数据库 schema 变更的发布,迁移安全性维度按 P0 对待,未做备份即迁移属阻断项。

## 审查清单
每维度可直接执行（明确检查动作+判定标准）,禁空洞套话:
- [ ] 发布清单完整: 对照任务书 scope 逐项枚举本次变更面（服务/配置/数据/脚本）,清单外变更显式登记,无遗漏项
- [ ] 回滚预案可执行: 预案含逐条步骤（可逐行照做）+每步验证点,能说明如何确认回滚成功;预案缺失或不可执行按 P0 处理
- [ ] 配置与环境变量核对: 新环境配置项与现网逐项 diff,新增/删除/改值都有指认;无依赖未声明环境变量的隐式行为
- [ ] 数据库迁移安全性: schema 迁移可回滚（有反向迁移或备份点）;迁移前备份可恢复性已验证,大表变更评估锁与时长影响
- [ ] 依赖服务与版本矩阵: 列出全部依赖服务与版本,兼容性对照通过;版本升级项有升级后验证步骤,无裸升无验
- [ ] 灰度与影响面控制: 有灰度/分批策略（比例+观察期+放量条件）,影响面（用户量/区域/功能）有量化描述,非一把全量裸上
- [ ] 监控告警就位: 关键指标（错误率/延迟/队列积压）在发布后 30 分钟内可观测,告警阈值与升级路径已配好
- [ ] 发布窗口与通知: 窗口避开业务高峰,受影响方（用户/运维/客服）通知文案与时间点已定,无静默上线
- [ ] 部署后冒烟验证清单: 冒烟用例覆盖主路径 ≥1 条+关键接口 ≥2 个,每例有判定标准（非「看了下正常」）
- [ ] 权限与凭据面复查: 新服务/新密钥的权限最小化确认,凭据存放位置合规（无明文入库/入代码）,旧凭据回收路径明确
- [ ] 越界自检: 变更文件清单与任务书 scope_files 逐一对照,未触碰范围外文件

## 证据要求
- 呼应 Rule 43.1 证据先行:每个「已完成/正确/通过」的重要声称必须附机器可复现证据（命令+关键输出 / Read 路径+关键行 / diff 行号,三选一以上）。
- 发布审查的证据=预案文档实际条款（file:line）/演练命令输出/dry-run 结果,禁「预案应该够用」式结论;关键预案项须有演练或 dry-run 记录。
- 未演练项显式登记「未演练+风险」,禁止混入通过表述;CHANGES_REQUESTED 的证据指向具体 file:line,建议修法可直接执行。
- 返回模板 evidence 字段的结论行必须可重跑复现（同一 dry-run/同一文档条款即可复核）;证据与结论同会话落盘 checkpoint/findings,保证跨会话可复查。
- 证据路径统一写 `file:line` 或「命令+关键输出」两种形式,与兜底池其他成员对齐。

## 输出合约
- 结论二值: `APPROVED`（清单全过且 P0/P1 = 0）或 `CHANGES_REQUESTED`（任一 P0/P1 命中）,结论置于审查报告首行供机械解析。
- CHANGES_REQUESTED 必须附逐条问题清单,格式每行一条: `[P0|P1|P2] <file:line|预案项名> — 问题 — 建议修法`。
- 修法须给出补齐项的具体形态（补预案步骤/补备份验证/补告警配置/补演练记录）,可直接分派执行。
- 级别定义: P0=阻断（不可发布/回滚预案缺失/数据不可逆/备份未验证）; P1=发布前必须修复; P2=建议不阻断。
- 回滚预案缺失按 P0 处理是发布类的特化规则,其余技能按通用 P0 定义执行。
- APPROVED 必须附各维度实际核对/演练的证据关键输出摘要;「无证据应该没问题」不受理。
- 审查完成后清除本次 checkpoint 中的临时中间产物,只保留结论与证据索引。
- 发布类结论有效期为发布窗口前 24h,窗口外须重跑关键三项（回滚预案/备份/冒烟）再放行。
