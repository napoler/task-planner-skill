# general-review · 通用综合质量审核

review-library 兜底池的通用质量审核技能,Rule 42.2 四级检测链中的「兜底的兜底」。当任务产出类型未命中对应领域专用审核技能（code/test/security/image/content/documentation/data/UI/release）,或任务为混合领域、无单一专用技能可完整覆盖时,用本技能做最终综合质量审查。
输出二值 `APPROVED` / `CHANGES_REQUESTED`,每条结论必须附机器可复现证据。

## 触发条件
- Rule 42.2 四级检测命中第④层「task-planner 内置 review-library 兜底池」,且任务类型未命中池内任一领域专用审核技能（其余 9 个）→ 命中本技能作通用兜底。
- 任务产出为混合领域（文档+配置+脚本混合等）,无单一专用技能可完整覆盖。
- 交付前做「最终综合质量门」,或用户/审查者显式要求「通用综合质量」审查。
- 命中专用技能的任务优先专用技能;本技能只处理专用技能通过后的未覆盖余量,不替代、不叠加。
- 纯调研/只读、无交付物产出的任务不触发。

## 审查清单
十维度各 1 条起,每条可直接执行（明确检查动作+判定标准）,禁空洞套话:
- [ ] 正确性: 对每条核心路径跑最直接验证命令（测试/dry-run/关键行重读）,确认行为与任务书规格一致,不止「能编译/能跑」
- [ ] 完整性: 对照需求清单（VC/acceptance/决策点）逐条勾选,确认无遗漏项、无范围外扩写,未做项显式登记
- [ ] 一致性: grep 新增措辞/接口/数字字面的全局锚点,确认与既有条款无语义漂移或互斥（如「三级」vs「四级」措辞、越界数字）
- [ ] 可维护性: 确认未引入死代码/重复逻辑/硬编码魔数;改动最小且注释含「原因+时间+原行为」
- [ ] 文档: 确认改动的函数/脚本/配置项 docstring/注释完备,无 TODO 占位替代修改说明
- [ ] 测试: 跑既有 selftest/测试套件 0 回归;新功能无测试时显式登记「无测试+原因」,不静默跳过
- [ ] 安全基线: 确认无硬编码密钥、无权限提升、无未授权的 `rm -rf`/`git reset --hard`/`curl|bash` 类危险命令
- [ ] 性能基线: 确认未引入高频 O(n²) 循环/大文件整读入内存;关键路径无新增阻塞等待
- [ ] 可回滚性: 确认回滚点明确（worktree/分支/基线 commit）,改动未混入用户工作树,且可演示复原
- [ ] 证据留痕: 报告中每条结论附机器可复现证据（file:line/命令+输出）,禁「推测/应该没问题」
- [ ] 越界自检: 变更文件清单与任务书 scope_files 逐一对照,未触碰范围外文件
- [ ] 幂等性: 同一操作重复执行结果一致,无重复项/脏数据类副作用累积
- [ ] 回归抽查: 未改动路径抽查旧行为样本,确认无静默回归
- [ ] 配置/环境: 配置项取值与文档一致,无默认值掩盖缺失（`dict.get` 兜底、`x or default` 混淆 falsy）
- [ ] 命名/可读性: 新增命名与实体语义相符,无过度抽象、注释与代码无语义落差

## 证据要求
- 呼应 Rule 43.1 证据先行:每个「已完成/正确/通过」的重要声称必须附机器可复现证据（命令+关键输出 / Read 路径+关键行 / diff 行号,三选一以上）。
- 未验证内容显式登记「未验证」,禁止混入完成表述;CHANGES_REQUESTED 的证据指向具体 file:line,建议修法可直接执行。
- 返回模板 evidence 字段的结论行必须可用同一命令重跑复现,抽查即对证据原文。
- 证据与结论同会话落盘 checkpoint/findings,保证跨会话可复查。
- 本节为兜底池 10 技能共同对标的最小证据标准:证据路径统一写 `file:line` 或「命令+关键输出」两种形式,复查格式统一。

## 输出合约
- 结论二值: `APPROVED`（清单全过且 P0/P1 = 0）或 `CHANGES_REQUESTED`（任一 P0/P1 命中）,结论置于审查报告首行供机械解析。
- CHANGES_REQUESTED 必须附逐条问题清单,格式每行一条: `[P0|P1|P2] <file:line> — 问题 — 建议修法`。
- 级别定义: P0=阻断（错误/安全风险/不可回滚）; P1=合并前必须修复; P2=建议不阻断。
- APPROVED 必须附各维度实际跑过的证据关键输出摘要;「无证据应该没问题」不受理。
- 审查完成后清除本次 checkpoint 中的临时中间产物,只保留结论与证据索引。
