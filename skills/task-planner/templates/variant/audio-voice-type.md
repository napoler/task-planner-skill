## Phases（五原子步骤）

### Phase 1: ① 音色声明核对
- [ ] 剧本音色声明块逐角色核对（与角色卡声线字段逐字一致）；缺块/漂移=回 script-dev 域补正（STOP 路由）；产出=音色核对行（状态：待建表）
- **V-N:** VC-2, VC-3
- **Status:** pending
- **Executor:** 判定执行体（子代理核对）+主进程复核

### Phase 2: ② 语言锁三层核对
- [ ] 逐条台词语言判定（行级标签＞角色语言表＞默认中文）；非中文角色按表豁免登记；产出=语言核对行（状态：待建表）
- **V-N:** VC-3, VC-5
- **Status:** pending
- **Executor:** 判定执行体

### Phase 3: ③ 声线参数表锁定
- [ ] 逐角色声线定值+英文音色子句+TTS 参数位回填；全角色锁定登记行（未锁定禁合成）；产出=声线表（状态：locked）
- **V-N:** VC-2, VC-1
- **Status:** pending
- **Executor:** 主进程

### Phase 4: ④ 对齐核查
- [ ] 逐条台词核查（配音段×时码×口型语言观感×字幕一致性——字幕/界面文本=后期叠层零生成核对）；FAIL 回改环（静默）；换声冲突=STOP 用户确认（合法打断）
- **V-N:** VC-5, VC-4
- **Status:** pending
- **Executor:** 核查执行体+主进程复核

### Phase 5: ⑤ 登记收尾
- [ ] 声线表/语言表归档登记；换声变更记录+在途通知；单份收尾报告（逐角色+逐条核查结论）
- **V-N:** VC-6, VC-5
- **Status:** pending
- **Executor:** 主进程

## 🔗 隔离与静默纪律
- 核对执行体独立于写词执行体；主进程复核=仲裁
- 静默环：对齐回改不呈送中间态；用户可见=换声确认、批次末收尾报告
- 换声纪律：角色卡变更记录+在途任务通知，双落登记
