# longform-continuity — 长文与连续创作连续性技能

## 何时必须使用
命中任一即应加载本技能并遵循其流程（模板/映射命中时亦强制）：
- 长篇小说、连载、剧集/多集剧情脚本、系列分镜等跨单元连续叙事
- 长论文、长报告、技术长文、长教程等需跨章节保持论点/术语/事实一致的内容
- 对既有长文做续写、改写、补写、扩写且存在前后设定/论证依赖

## 核心原则（对齐 Rule 107/22.4d/派发契约）
1. **项目级资产先于计划内碎片**：大纲、设定库/圣经、知识库、脑图等落项目级固定路径；计划目录仅登记引用与本轮增量。
2. **先大纲后丰富**：先建立/校验总纲与分单元（章/集/节）拆解及单元接口，再写正文；无纲不盲写。
3. **动笔前全局检索**：写作/改设定前必须检索总纲对应段、设定库/知识库相关条目、continuity 台账及相关历史单元，**不得仅依赖紧邻单元或记忆**。
4. **最小必要上下文加载**：按单元分段推进，每次只加载本单元所需的“总纲段+相关设定/知识+接口与必要前序摘要”，避免整篇整书塞入上下文。
5. **写后沉淀回写**：单元完成后更新台账并回写受影响的项目级资产（大纲进度、设定、知识、脑图节点/伏笔状态）。
6. **冲突显式裁决，禁止静默覆盖**：发现与既有设定/前文冲突→标记并裁决，必要时回写资产与历史索引；禁止悄悄改掉早期设定。
7. **里程碑全局一致性审查**：按阶段/卷/章节组通检大纲-设定-知识-正文的一致性。

## 项目级连续性资产包（推荐默认，按实际项目调整）
| 资产 | 推荐路径 | 内容 |
|---|---|---|
| 总纲/主大纲 | `docs/<项目或系列>/outline.md` | 整体结构、分章/分集拆解、每单元目标与承上启下接口、当前进度 |
| 设定与世界观圣经 | `docs/<项目或系列>/setting-bible.md` | 人物/角色状态与关系、世界观规则、时间线、硬设定与禁改项 |
| 知识库/事实库 | `docs/<项目或系列>/knowledge-base.md` | 术语表、关键事实、论点与证据/来源锚、引用约定 |
| 脑图/结构图 | `docs/<项目或系列>/structure-map.md` 或 `.mmd` | 全局结构、依赖与伏笔/论证关系可视化（可选但长篇强烈建议） |
| 连续性台账（增量） | 计划声明路径或项目既有（如 `<plan-dir>/continuity-ledger.md`） | 单元增量事实、状态变化、伏笔埋设/回收、产出路径流水（不替代上述资产） |

## 标准执行流程
### A. 立项/开写前（大纲先行门）
1. 定位或创建项目级资产包；校验总纲与分单元拆解是否完整到当前目标范围。
2. 在 task_plan 中登记资产路径、当前目标单元与对应大纲段；资产缺失先补最小可用版本再动笔。

### B. 单元写作前（全局检索）
1. Read 总纲中本单元段 + 相关依赖段。
2. 检索/Read setting-bible、knowledge-base 中与本单元相关条目（人物/时间/术语/论点/设定）。
3. Read continuity 台账 + 紧邻前序单元 + 台账/大纲指向的相关历史单元。
4. 输出简短“一致性检查清单”（本单元必须遵守的设定/接口/禁改项）后再写。

### C. 单元写作中（分段与受控上下文）
- 按章/节/集自然单元推进；复杂单元再拆子步骤，但保持对总纲接口的对齐。
- 需要新设定/新论点时，先判定是否与既有资产冲突；冲突走裁决流程后再落笔。

### D. 单元完成后（沉淀回写）
1. 更新 continuity 台账（增量事实、状态变化、伏笔/接口变更）。
2. 回写总纲进度与接口、setting-bible、knowledge-base、structure-map 受影响节点。
3. 对照资产做本单元一致性自检；记录遗留风险。

### E. 里程碑复审
- 每完成一组单元/一卷/关键转折点，执行全局一致性审查（设定、时间线、术语、伏笔/论证链）；发现漂移立即修复并回写资产。

## 长文本优化策略（执行要点）
- **分段推进**：避免一次生成超长跨度；以单元为交付粒度。
- **最小必要上下文**：只带“总纲对应段 + 相关设定/知识 + 必要接口 + 目标单元要求”。
- **显式接口**：每单元在大纲中记录输入状态与输出状态（人物/时间/悬念/论点进度）。
- **检索优先于记忆**：不确定即查资产/台账/历史文本，不凭印象续写。
- **变更可追溯**：设定或论点变更必须登记原因、影响范围与回写位置。

## 子代理/协作要求
- 派发连续写作任务时，prompt 必须携带项目级资产路径、台账路径、前序与相关历史产出路径及本单元大纲段定位（对齐 Rule 107.2/dispatch 22.4d/派发模板）。
- 子代理首动作：加载本技能并完成全局检索与一致性检查；未完成不得动笔。
