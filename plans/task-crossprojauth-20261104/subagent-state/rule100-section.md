**临时目录统一协议（P0）**：
- **100.0 总纲（统一落点，定义）**：任务执行的一切**临时产物**（临时文件/草稿/构建输出/下载文件/渲染输出/中间缓存）统一放**当前项目**的 `tmp/` 目录（绝对路径 = `<project-root>/tmp/`，project-root = 任务所属项目根 = 任务 CWD/git 仓根，按部署环境代入实际值）；git worktree 也放到本项目临时目录 = `<project-root>/tmp/worktrees/<task-id>`（子目录名 = task-id，basename 口径不变，smart-merge-back.sh/check-conflicts.sh 的 basename=task-id 兼容逻辑不受影响）。**「当前项目」=任务所属项目（任务 CWD），不是模型运行位置**；跨项目放临时产物=99.0 同边界越权（别的项目 tmp/ 不写，99.1 门不变）。
- **100.1 工作树内放生命周期**（替代 2026-08-29 仓外集中目录约定；SOP=`references/worktree-isolation.md` §3/§4 已随动）：创建 `git worktree add <project-root>/tmp/worktrees/<task-id> -b wt/<task-id> <base-branch>` → 开发（worktree 绝对路径，CWD 不迁移）→ 每 Phase 提交（Rule 27）→ 全 VC 复验过回主仓合并（`smart-merge-back.sh <worktree-path>`，basename=task-id 兼容不变）→ 清理 `git worktree remove <project-root>/tmp/worktrees/<task-id> && git branch -d wt/<task-id>` + `ls <project-root>/tmp/worktrees/` 孤儿扫描（遗留目录=冲突信号③同语义）。旧仓外路径 `<repo-parent>/<repo>-worktrees/<task-id>` **废止（2026-11-04）**：存量旧路径 worktree 按 SOP 逐个清理，新任务禁用旧路径。
- **100.2 .gitignore 保证（确保后期执行的落点验证）**：任务起点（计划创建/隔离决策时）检查 `<project-root>/.gitignore` 是否含 `tmp/`——缺则**追加一行 `tmp/`**（既有 .gitignore 追加行+一行注释，禁重排全文件；项目无 .gitignore 则创建）并 Decisions Made 登记一行（对象=该 .gitignore 路径）；验证点=既有命令 `git check-ignore -q tmp/` exit 0（非新增守护）。保证目标=① tmp/ 不污染 git status（未跟踪噪声）② 临时产物不误入库 ③ 宪法 §五 射程限定（`tmp/`、`output/` gitignore 区机械写=P1 档豁免）前提成立。
- **100.3 边界与豁免（窄定义）**：① `tmp/` = 非受管区（gitignore 区）——机械写（工具产物/草稿/缓存落盘）免 P1 授权（宪法 §五 豁免口径，同 `output/` 族）；② `tmp/worktrees/` 内 worktree 内容是 worktree 自身 git 受管的（其内部 HEAD 管理边界不变，主仓 .gitignore 忽略的是路径不是 worktree 内部 git 状态），worktree 内提交仍走 Rule 27；③ **覆盖/删除 tmp/ 下既有数据仍需授权**（宪法 §五 射程限定原条款：豁免仅限机械写新产物，既有数据覆盖/删除保留授权要求）；④ 别的项目的 `tmp/` = 跨边界写（99.1 门，本条不扩 99 例外清单，100.4 的宪法对齐也不改变本条边界）。
