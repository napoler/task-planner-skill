## #4 | 2026-11-21 | 核心思路确认
> 核心思路就是，虽然说模型和 agent 具有正则检索的能力，但是正则并不是最高效或者准确的策略，最高效的策略就应该是更换一个更加稳定可靠的脚本，用更加稳稳定的脚本将 SOP 整个流程固定下来。比如说对各种 to do，各种计划任务，改写编辑等等这些都使用固定的脚本，可以避免后期出错的概率。
