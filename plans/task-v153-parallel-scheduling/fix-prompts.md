# Fix Prompts — 无来源虚构内容（幻觉补位）专项修正提示词组

> 来源事故：2026-10-09 task-v153 编写 findings.md 时，在 Visual/Browser Findings 模板空段填入一段本会话无任何来源的内容（食堂菜单/牛奶照片描述），被主进程当次自查发现并删除。
> 错误类别：反造谣铁律（宪法 §三）P0 面——模板空段落被「合理推测的具体化」填充。
> 产物定位：三条提示词=事后审计（A）/事前自检（B）/传播面契约行（C），可直接复制使用；Agent 派发型用法已带 22.4 契约要素。

## 提示词 A — 溯源审计（事后审计，派子代理或主进程自查均可）

```
【目标】对 <目标文件绝对路径> 做逐句溯源审计（无来源虚构内容专项，防宪法 §三 反造谣铁律违反）。

【背景】2026-10-09 事故：在模板空段被填入无来源「具体事实」（如虚构的照片/事件描述），当次自查删除。本审计用于对任何疑似文件做同类清零。

【审计口径】
- 把目标文件切成「事实单元」：每条含具体事实的句子或表格单元格=1 个单元（具体事实=时间/数字/人名/事件描述/文件内容/截图照片描述等）
- 逐单元三态判定：
  有源=附 file:line / URL / 命令输出原文 / 本会话工具调用记录 四者之一；
  无源含事实=无上述来源却含具体事实（含「合理推测的具体化」「替用户补细节」）=幻觉候选=违规；
  显式占位=「（本任务暂无…）」「未验证」类合法形态=合规。
- 只审计不改写：违规单元的处置=删除或降级为显式占位，由调用方执行；无源内容禁止「补一个源」蒙混。

【输出契约】三文件绝对路径（按需）：<task_plan.md>/<findings.md>/<progress.md>；输出=审计表（单元位置 | 事实摘要 | 三态判定 | 源锚或「无」 | 处置建议）+ 总计行（违规数/合规数），统计类逐行原文禁自报汇总。

【铁律】只读目标文件；只写审计报告到 <输出路径>；不确定的单元一律判「无源含事实」从严。
```

## 提示词 B — 写入前自检 5 问（事前，主进程/子代理写入任何文档前过一遍）

```
即将写入 <文件> 的任何段落，先逐段回答，任一问不过=改写为显式占位：
1. 这段里每个具体事实（时间/数字/人名/事件/照片描述/文件内容）我在本会话有第一手来源吗（工具调用记录/Read 过的文件/子代理返回）？
2. 我是否正在填模板空段？——空段一律写「（本任务暂无…）」或「未验证」，禁止自由发挥。
3. 读者能按我写的锚点复核吗（file:line 可定位/命令可复现）？
4. 会话此刻中断，明天重启，这段内容还能从磁盘证据重建吗？
5. 我写下的句子是「我记得/我读到过」还是「我觉得应该有」？——后者一个字都不许落盘。
```

最小可执行版（贴在手边）：**「无源不写，空段占位，写必带锚。」**

## 提示词 C — 派发契约行（传播面，嵌入子代理任务书防幻觉段）

```
【防幻觉契约】你的全部事实性输出必须带来源锚（file:line / 命令原文 / URL / 检查已读文件的区段行号）四者之一；禁止无来源的具体化（包括把推测写成事实、替调用方补细节、填模板空段）；信息缺失一律显式写「未验证」或「暂无」并说明缺什么；结论区必须「事实+锚点」成对，无锚点行=违规退回；禁止以「合理推断」为由省略锚点。
```
