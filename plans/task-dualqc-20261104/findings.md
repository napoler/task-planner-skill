## Rule 103 设计稿（S1 落地蓝本 — Phase 1 产出）

**标题**：`### 103 双轮质检与同步完整性审查（P0 — task-dualqc-20261104，目标：子代理产出零带病交付+多文件修改零遗漏；判定面=派发型 S-unit 产出轮；衔接 84.4/84.7/96.2/22.3/74.3，原文零改动）`（落 task-dispatch 卫星尾部 Rule 96 块后；标题形态以 96 块现形为准）

- **103.1 定义与适用面**：双轮质检=派发型 S-unit 产出的两道检核——第一轮=执行体自审（返回前），第二轮=主代理派全新子代理独立复检（收到返回并 Read 产出后）。适用面=派发型 S-unit 实质产出（新增/修改仓库受管文件、内容产出）；豁免面=103.7。
- **103.2 第一轮自审契约（执行体义务）**：完成 S-unit 后、返回前，按任务书 §3 验收标准逐项自核执行度（产出存在性/完整性/正确性抽样）；自审结论写 checkpoint 自审段（逐条验收项→自核结果+证据锚 file:line+遗留缺口）；返回消息 22.4b 八字段契约零改动（结论经 checkpoint 承载，字段内引锚）。自审=执行度申报，非完成声称替代（Rule 51/84.4 仍管完成面）。
- **103.3 第二轮独立复检契约（主代理义务）**：Read 产出（84.4 硬门不变）→派**全新子代理**复检（与执行体零共享上下文，防上下文污染偏移）；复检体选型走 Rule 52 specialist-first（代码→general-reviewer/Code Reviewer 系；全类型→general-reviewer；对抗挑刺→critic）；复检只读：禁改产出/禁重做/禁扩范围；多文件变更集（≥2 受管文件）复检任务书必附同步核对清单（103.6）。
- **103.4 复检升档映射与封顶**：按 96.2 三档表——轻档（haiku-1）→复检中档（sonnet-1）；中档（sonnet-1）→复检重档（GLM5.3/Opus 级）；重档→封顶同档（独立上下文已消除污染增量；质量争议升级 decision-arbiter GLM-5.3 强档）。派发 model 参数显式指定，禁降档复检；22.3 provider 降档链仍适用、降档登记 scaling-redispatch。
- **103.5 复检任务书简洁直接四要素（低资源约束）**：①对象=产出文件绝对路径清单；②验收标准=任务书 §3 验收原文逐条（禁改写扩散）；③判定口径=逐条 PASS/FAIL+证据锚（file:line），结论单行；④禁令=只读不改/不重做/不新增需求/不扩范围/输出精简。受 22.4b 契约照常约束，禁背景铺陈/流程叙事/重复计划全文；复检体写独立回执 checkpoint（`<plan-dir>/subagent-state/{seq}-{verifier-type}.md`）。
- **103.6 同步完整性审查（每轮修改后漏改检测门）**：触发=修改轮完成且变更集 ≥2 受管文件（强制）；单文件小改=主进程翻转门自核（分级门控控成本）。关联面推导四族：①同族字面面（纪元/计数窗字面族）②引用面（互引/指针/路由表/索引）③部署镜像位（卫星多副本+多部署位同路径族）④受影响断言面（selftest/守卫断言）。产出=同步核对清单（关联文件+逐文件核对项+状态）落 checkpoint/progress；门控=清单全绿才可翻转 Phase complete（与 19.2/84.3 并列翻转前置）；多文件变更集复检必附清单。分工声明：74.3=计划内枚举面、越界自检=不该改的改了、本条=该改的漏改——三者互补零重复。
