# Knowledge Brief: S77 审查知识底座

## §1 可复用知识

- S77 判定维度：输入→输出确定性 + 步骤顺序固定 + 可复用性 = 机械；需判断权衡 + 多解 + 可换序 = 智能
- S77 豁免：单步工具/脚本 skill（无 Phase）豁免；纯查询类只读 skill 豁免智能描述
- S77 审计检查项 77.1-77.6 全文见 references/mechanical-adaptive-split.md §4

## §2 易错点

- 混合步骤（M+A）须拆分为机械子动作 + 智能子动作两条
- 智能步骤禁止写死单一路径（反模式）
- 机械步骤必须有 SOP 锚点（模板/脚本/固定 SOP 段）
