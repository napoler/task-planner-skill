# 用户会话逐字记录（user-session-log）— 只写不改（Rule 80）

> **WHAT**：记录本任务周期内每一次用户提交的任务需求与对话内容，**逐字抄录**，禁转译/缩写/合并（口径同 Rule 51.1）。
> **WHY**：会话异常/压缩/重启会丢失用户原始发言；本文件是用户意图的持久化权威源，恢复时**先读本文件再读 task_plan.md**，杜绝凭记忆转译导致的指令漂移（task-v169 R1-R5）。
> **只写不改铁律（Rule 80.2）**：历史条目禁修改、禁删除、禁重排；唯一合法写操作=**文件尾部追加**（append-only）；发现历史条目有误→在末尾追加「更正说明」新条目，禁回头改旧条目。
> **写入时机（Rule 80.3）**：用户发言到达后**立即追加**（宪法 §八 即时落盘纪律），禁止攒批/deferred。
> **写入者**：主进程单写（同三文件罗盘单写者纪律）；子代理只读不改。
> **与 task_plan.md 的关系**：task_plan.md 受 attest 哈希锁（Rule 20/51.7，改即 [PLAN TAMPERED]），故用户会话记录**禁入 task_plan.md 正文**；task_plan.md「🗣️ 用户会话逐字记录」指针区块指向本文件。
